# Elgato World Finder

A powerful and user-friendly Lua script for Growtopia that automates the process of generating and joining random worlds. Equipped with a clean ImGui interface, this script allows you to customize how random world names are generated to suit your needs.

## Features

- **Custom Length:** Easily adjust the length of the generated world name.
- **Alphanumeric Toggle:** Option to include or exclude numbers in the generated name.
- **Custom Prefix/Suffix (Save Word):** Lock a specific word at the `FRONT` or `BACK` of the generated name (e.g., if Save Word is "MBUD", it generates "MBUDXXXX").
- **World History List:** Automatically records and lists all worlds you have successfully entered during the session.
- **Shortcut UI:** A minimalistic floating shortcut button to quickly generate and join a world without opening the main menu.
- **Clean UI:** Powered by Lua-ImGui-Builder for a modern dark-themed interface.

## How to Use

1. Execute the script using your preferred Growtopia Lua executor.
2. The **Elgato World Finder** menu will pop up.
3. Configure your desired settings (Length, With Number, Enable Custom Word).
4. Click the **FIND WORLD** button on the main menu, or enable the **SHORTCUT** for a smaller UI.
5. The script will automatically generate a name and attempt to join the world.
